About this project

What it does

A registered user enters details about a bank client. A trained machine learning model estimates the probability that the client will subscribe to a term deposit. Each prediction is saved so it can be reviewed later.

Dataset

UCI Bank Marketing data (bank-additional-full.csv): phone marketing campaigns of a Portuguese bank, recorded from May 2008 to November 2010. It has 41,188 rows. The target is whether the client subscribed (yes / no), so this is a binary classification problem.

Input features used (11):

  • Numeric: age, contacts in this campaign, contacts before this campaign
  • Categorical: job, marital status, education, housing loan, personal loan, contact type, month of contact, outcome of the previous campaign

Source: Moro, Cortez and Rita (2014), "A Data-Driven Approach to Predict the Success of Bank Telemarketing", Decision Support Systems.

Machine learning approach

  • Algorithm: Random Forest classifier (300 decision trees that vote).
  • Categorical fields are one-hot encoded; no scaling is needed for tree models.
  • Only about 11% of clients subscribed, so classes are balanced with class weights and the data is split 80/20 with the same yes/no ratio in both parts.
  • The call duration is not used, because it is only known after the call ends.
  • The month list covers March to December, because the data has no calls in January or February.

Limitations

  • Accuracy alone is misleading here: always answering "no" would already be right most of the time. Precision, recall and ROC-AUC give a fairer picture.
  • The model finds many, but not all, subscribers and also produces false alarms.
  • The data comes from one bank in Portugal between 2008 and 2010 and may not match other markets or later years.
  • This is a learning project. Do not use it to make real decisions about people.
